# Git

- **Never create a branch without explicit permission.** Work on the current
  branch, including when it is `main`. If a new branch seems warranted, ask
  first and wait for a clear yes.
- Commit, merge, push, and force-push only when asked.
- Conventional Commits for every commit message: `feat:`, `fix:`, `docs:`,
  `chore:`, `refactor:`, `test:`, `perf:`, `build:`, `ci:`.
